# 3D Assets Directory

Letakkan file 3D model avatar Anda di sini:
- `avatar.glb` : Model 3D utama (Low-poly glTF Binary) dengan animasi (Clip: `0` = Idle/Happy, `1` = Poke reaction, `2` = Wave).

Filament akan memuat file `avatar.glb` secara otomatis dari folder `assets/` pada saat overlay service dijalankan.
